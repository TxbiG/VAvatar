# VAvatar
VAvatar is an open-source cross-platform VTuber tool. Built off the Moss Framework.

## Features
- Graphics support OpenGL, Vulkan, DirectX 11 & 12
- Supports Windows 10 & 11, Mac, and Linux
- Supports both 2D and 3D for PNGTuber, 2D-realism, and 3D-VTubers.
- Supports Collisions and Physics

## Build
```
mkdir build
cd build
cmake ..
cmake --build
```
